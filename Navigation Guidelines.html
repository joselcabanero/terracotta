Navigation

Quiet navigation, one list for every layout

How a Terracotta app moves people around: a white-paper sidebar on iPad and desktop, a bottom tab bar and More sheet on iPhone, and a proper home-screen install. The structure comes from the Venture Desk navigation; colour, type, shape and icons are Terracotta's.

Calm by default

Idle rows are --fg2 on white paper; navigation never sits on cream. Red appears only on the current page and on counts.

One "you are here"

Only the exact current page gets the red-tint pill and red marker. A parent never lights up alongside its child.

Depth only where you are

Subsections expand inside the current section only, so the list reads as one level.

One list, every layout

Sidebar, tab bar and More sheet are filtered from the same nav array and permissions, so they can't drift apart.

Tokens only

Every colour is a Terracotta variable. No raw hex or palette classes inside navigation components.

Follow the platform

Tab bar and sheet on iPhone, sidebar on iPad and desktop, and a real home-screen install.

iOS & iPadOS install

Opened from the home screen, the app runs without Safari's address bar and toolbar. These settings make that work and keep the EA app mark on the icon.

Do

  • Ship a manifest with display: standalone.
  • Set appleWebApp: { capable: true, statusBarStyle: 'default' } for older iOS.
  • Provide an apple-touch-icon for each size: 180 for iPhone, 152 and 167 for iPad. Use the EA app mark (red rounded tile, white EA). iOS rescales a single icon badly.
  • Set themeColor to #FFFFFF (--background), and add a dark value when the dark theme ships.
  • Version the service worker and bump it to push a brand change.

Don't

  • Set appleWebApp.title. It overrides the manifest's short_name and pins every client to one name.
  • Block zoom with maximumScale or userScalable: false. People pinch-zoom tables of figures.
  • Add viewportFit: 'cover' unless the whole shell pays back every inset.

Rules for every app

Highlight exactly

A nav row lights only on its exact page. Child rows may match by prefix.

Tokens, enforced

Forbid raw hex and palette classes such as bg-gray-100 in components, and enforce it with a lint rule or test.

Numbers line up

Counts and figures use tabular-nums. Mono is for code and IDs only.

Colour means status

In navigation, red is "you are here" or "needs attention", never decoration. Yellow stays the light point and never marks status.

Hidden isn't secured

Hiding a nav item is not access control. Gate the route or page itself.
