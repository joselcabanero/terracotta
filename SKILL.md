If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.

Key facts to internalize before you start:
- **Warm + appetising.** Warm neutrals (paper/cream/sand) do the work; charcoal ink (`#1E1E1E`) is the primary action color; brand coral `#DE5533` (darker pair brick `#BC2D29`, tint `#FDECE4`) is the identity/selected accent, and amber `#FFA103` is the highlight. Domain color (sector / node / status palettes) only ever encodes data.
- **Type:** Inter for all UI (small, tight — 24px page titles max), IBM Plex Mono for micro-labels/numerics.
- **Shape:** borders over shadows, 4px grid, `rounded-xl` (12px) cards, flat white surfaces, quick 0.15s fades.
- **Icons:** Lucide, 16px, outline. Never hand-roll SVG icons or use emoji.
- Voice is terse, functional, impersonal — an internal analyst tool, not a consumer brand.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
