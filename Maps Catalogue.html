Maps & geography

Maps on the brand hierarchy

Geography is data, not drawing — every map renders real Natural Earth geometry. Land is EAV Grey, water is paper, and the palette follows the same rank order as the charts: red for what matters most, the yellow light point for headquarters.

Hub network

World · point map

Natural Earth projection, land in grey. Hubs are red points with a soft pulse ring; headquarters carries the yellow light point. Labels in Rubik 12/500 with a paper halo.

Coverage

World · categorical

Three states only: active hub country (red), partner network (orange), no presence (grey). Never more than three categorical fills on one map.

Choropleth

Region · sequential

Mercator fitted to the region. Warm sequential ramp — Dark Cream → Orange → Red → Burgundy — in four classes max; no-data countries in light grey.

Region focus

Country · cities

Cream ground, focus countries in Dark Cream, neighbours in light grey. HQ light point, hub red, partner cities burgundy; labels haloed in cream.

Bubble map

World · proportional symbols

Circle area encodes the value at each country centroid. The top three take rank colors and a label; the rest sit in warm grey at 45% so the field stays readable.

Flow map

Connections · great circles

Great-circle arcs from headquarters, all in red at 55% with width by weight; endpoints as burgundy dots. One origin per map — never a web.

Real geometry

Load Natural Earth TopoJSON and project with d3-geo — never freehand outlines. Natural Earth for the world, Mercator fitted to a bounding box for regions. Antarctica is dropped.

Quiet base, loud data

Land EAV Grey with white hairline borders, water paper (or cream for a focus region). No relief, no tiles, no gridlines. Colour is spent only on the data layer.

Rank, then colour

Same order as charts: Red → Orange → Burgundy → Yellow (light point, HQ only) → Dark Cream. Sequential maps use the warm ramp in ≤4 classes; categorical maps use ≤3 fills.

Geometry: Natural Earth via world-atlas (public domain).
